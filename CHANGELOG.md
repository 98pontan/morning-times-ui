# Changelog

All notable changes to the UI. Versions follow [semantic versioning](https://semver.org).

## [0.1.0] - unreleased

First versioned release.

### Added
- Login and logout with Keycloak; settings and edit controls only for logged-in members of `newspaper`.
- Personal watches and alerts when logged in; visitors see the defaults.
- Version in the footer.
- Weather map of Sweden with day buttons, a time slider and forecast charts per county.
- "El" page: live map with zone prices and flows, production mix, hourly prices, weekly outlook, reactors.

### Changed
- CI: `latest` only follows main; `v*` tags give versioned images.
